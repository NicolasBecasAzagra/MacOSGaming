Built from the Ground Up for Mac Gamers

Combining the power of Swift 6, Wine, DXMT, and deterministic hardware inspection.

⚡

Native Swift 6 & SwiftUI

Instant startup, zero runtime wrapper bloat (<60 MB memory footprint), and deep integration with Darwin/Mach kernel APIs and Metal 3 pipelines.

🛡️

Anti-Cheat Sentinel Gate

A deterministic pre-flight policy checker that strictly blocks games requiring kernel-level drivers (Ring-0) before execution, keeping your system safe and clean.

🩺

Hardware Readiness Score

Automated evaluation of your Apple Silicon tier, unified memory contention, Rosetta 2 runtime readiness, and macOS 15+ AVX2 instruction support.

📚

Steam Library Discovery

Automated ACF manifest parser that detects your installed Windows and Mac titles, matches them to validated profiles, and provisions sandboxed prefixes.

📦

Zero-Vendoring Architecture

We never track or ship pirated binaries or proprietary Apple frameworks. Wine, DXMT, and DXVK are fetched transparently on user request.

🔒

Zero-Leakage Privacy

Automated anonymization strips absolute paths and personal usernames from validation telemetry. Telemetry is strictly opt-in and off by default.

Get Started in Seconds

Run via Swift Package Manager without complex installation steps.

zsh — Terminal 
# 1. Clone the repository
git clone https://github.com/NicolasBecasAzagra/MacOSGaming.git
cd MacOSGaming

# 2. Run the native SwiftUI desktop application
swift run MacOSGamingApp

# 3. Or use the powerful CLI tool directly
swift run macosgaming doctor
  GAMING READINESS SCORE: [ 100 / 100 ]

# 4. Launch your Steam game safely with Wine & DXMT
swift run macosgaming launch elden-ring --offline
